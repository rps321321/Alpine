# ADR 0023: v0.1 is a public source release

## Status

Accepted — 2026-08-20

The DCO contribution-attestation portion was superseded by ADR 0025 on 2026-08-22. The original decision text is retained below as history.

Project Alpine v0.1 is an Apache-2.0 source release with DCO 1.1 contribution attestation, private security reporting and narrow exact-deployment support claims. It publishes reproducible source, contracts, documentation and generated allowlisted evidence, but no model weights, runtime bundles, generated installation, raw private evidence, binary or installer. Third-Party Material keeps its original license boundary and attribution; public history is cleaned before publication without changing the intentionally public `rps321321 <prataprps321@gmail.com>` identity.
