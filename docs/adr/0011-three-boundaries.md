# Abliteration, Harness Policy, and Attack-Lab isolation are three layers

Abliterated Model behavior is a property of the weights. The Harness Policy Boundary is what OpenCode auto-allows, asks, or denies. The Attack-Lab Isolation Boundary is later real containment of a hostile or hijacked agent.

v1 uses the first two. It does not claim the third. Do not add OS isolation to v1 unless a later decision shows the Repo Loop cannot run safely without it.
