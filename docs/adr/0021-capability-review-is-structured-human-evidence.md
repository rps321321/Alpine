# ADR 0021: Capability review is structured human evidence

## Status

Accepted — 2026-08-20

Project Alpine's production Capability Review uses a strict, versioned evidence structure covering eight required capability categories through reviewer-chosen realistic scenarios. Alpine verifies completeness, identity binding and decision consistency; the named human reviewer decides whether an observed limitation is acceptable. Private tasks and observations remain private, secret material is neither stored nor hashed as proof, and any public review representation contains allowlisted structural facts only.
