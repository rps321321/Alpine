# Project governance

Project Alpine is currently maintained by the project owner. Ordinary changes to public `main` are expected to arrive through pull requests.

The canonical repository verification workflow must pass and review conversations must be resolved before ordinary merge. Branch protection should enforce those requirements after publication. An explicit maintainer/admin bypass may remain available for exceptional recovery, but direct writes and bypasses are not the normal development path; an emergency bypass should be followed by a public explanation and verification as soon as practical.

Technical decisions are recorded in `CONTEXT.md` and narrowly scoped architecture decision records. Qualification evidence does not settle product judgment, and a maintainer assertion does not replace automated evidence.
